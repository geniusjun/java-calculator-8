# 💪 프로젝트 개요

구분자와 양수로 이루어진 문자열을 입력받아 숫자를 추출하여 합을 구하는 게산기 로직을 구현한다.

# 📝 구현 기능 목록

### 문자열 입력 안내 문구를 출력한다.

    - [x] '덧셈할 문자열을 입력해 주세요.'를 출력한다.

### 문자열을 입력 받는 기능

    - [x] 문자열을 입력 받는다.
        - [x] 문자열을 입력받아 컨트롤러로 넘긴다.

### 문자열을 추출하여 합을 구하는 기능

    - [x] 구분자로 문자열을 나눈다.
        - [x] 나눈 숫자들을 Numbers로 저장한다.
        - [x] 각 숫자(Number)가 양수인지 검증한다.
        - [x] 각 숫자들을 합을 컨트롤러로 반환한다.

### 결과를 반환하는 기능

    - [] '결과 : (합)' 형식을 출력한다.
