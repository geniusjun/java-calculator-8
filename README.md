- [x] '덧셈할 문자열을 입력해 주세요.' 메시지를 출력한다.

### 덧셈할 문자열 입력 기능

- [] 덧셈할 문자열을 입력한다.
    - [] 뷰 레이어의 유효성 검증
        - [x] 빈 입력이 아님을 검증한다.
        - [x] 원본 입력 문자열 그대로 컨트롤러에 반환한다.
    - [] 뷰 -> 컨트롤러 레이어로 입력값 전달
        - [] 덧셈을 위한 Number 객체를 생성한다.
    - [] 도메인(Number) 레이어의 유효성 검증
        - [] 커스텀 구분자 검증
            - [] 입력이 "//"로 시작하면, 커스텀 구분자를 추출한다.
                - [] 첫 "\n"이 존재하는지 확인한다.
                - [] "//"와 "\n" 사이에 정확히 문자 1개가 존재하는지 확인한다.
        - [] 토큰화 검증
            - [] 구분자 집합을 구성한다: 기본(, :) U (커스텀 1개, 있으면)
            - [] 구분자 집합을 이용하여 문자열을 분리한다.
            - [] 빈 토큰이 있는지 확인한다.
            - [] 분리된 문자열을 반환한다.
        - [] 숫자 검증
            - [] 각 토큰이 정수 형태인지 확인한다.
            - [] 양수인지 확인한다.
            - [] 검증을 통과한 정수형 리스트를 반환한다.

### 덧셈 하는 기능

- [] 입력받은 양수 정수 리스트를 합산한다.
    - [] 합산 결과 반환한다.

### 결과를 출력하는 기능

- [] 덧셈 결과를 출력한다. (ex. 결과 : x)
